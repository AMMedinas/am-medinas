Control de Desperdicio de Papel

Metrocolor · app local en Python (para la PC de la planta)

⬇ Descargar app (un solo archivo)

No hay que descomprimir nada. Si el navegador pregunta, elige Conservar.

  1. Si la PC no tiene Python, instálalo desde python.org y marca Add Python to PATH (solo la primera vez).
  2. Abre Descargas y da doble clic en AppPapelMetrocolor.py.
  3. La primera vez escribe la clave de datos y presiona Enter. Se crea sola la carpeta Documentos\Control_Desperdicio_Papel_Metrocolor.
  4. La app se abre en el navegador. La ventana negra muestra el link para celulares; déjala abierta.
